# BinaField Contract Packs

`blueprint/` contains the bf-blueprint/1.0 Draft 2020-12 schema, governed component configuration/value schemas, rule/calculation grammar, validator registry, fixtures, generated bindings and contract hashes.

Runtime rule actions are restricted to SHOW/HIDE/ENABLE/DISABLE/REQUIRE/OPTIONAL/WARN/BLOCK_COMPLETE. Calculations are declared separately. Arbitrary JavaScript, SQL, shell and unrestricted HTTP are not part of the Blueprint contract.
