# BinaField release package

Release: `0.8.0-pilot.1`  
Release date: 2026-10-29  
Decision: **CONDITIONAL — suitable for the controlled pilot scope only**

## Package contents

- `RELEASE-MANIFEST.md` — version, commit, deployments, and package inventory.
- `EVIDENCE-INDEX.md` — Goals 1–5 completion records and supporting evidence.
- `UNRESOLVED-RISKS-AND-DEFERRALS.md` — open risks, owners, mitigations, and deferrals.

## Decision conditions

The release may proceed for the seeded controlled pilot when the pilot owner completes the sign-off form and uses the documented Android Chrome/PWA support cell. It must not be represented as broad Android/iPhone compatibility or production-scale readiness.
